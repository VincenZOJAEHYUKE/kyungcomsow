🚀 [경컴소] 제조 피지컬 AI Agent - MVP 실행 및 사용 가이드 
====================================================================

본 프로젝트는 AI 백엔드(FastAPI) 서버와 프론트엔드(웹 대시보드) 서버가 
동시에 실행되어야 정상적으로 작동합니다. 아래 순서대로 실행해 주세요.

[0단계] 필수 라이브러리 설치
터미널을 열고 아래 명령어를 통해 필요한 라이브러리를 설치해 주세요.
> pip install fastapi uvicorn ultralytics opencv-python python-dotenv pillow google-genai

[1단계] AI 백엔드 서버 실행 (포트 8080)
1. 터미널(명령 프롬프트)을 열고 현재 폴더(YOLO모델 폴더)로 이동합니다.
2. 아래 명령어를 입력하여 AI 서버를 실행합니다.
   > uvicorn server:app --reload --port 8080
   (또는 > python server.py)
3. 터미널에 "Application startup complete" 메시지가 뜨면 백엔드 준비 완료입니다.
   ※ 이 터미널 창은 절대 끄지 마시고 그대로 열어두세요!

[2단계] 프론트엔드 웹 서버 실행 (포트 3000)
1. 새로운 터미널(명령 프롬프트) 창을 하나 더 엽니다.
2. 마찬가지로 현재 폴더(YOLO모델 폴더)로 이동합니다.
3. 아래 명령어를 입력하여 웹 서버를 켭니다.
   > python -m http.server 3000

[3단계] 대시보드 접속 및 자동 검수 테스트
1. 크롬(Chrome)이나 엣지(Edge) 브라우저를 엽니다.
2. 주소창에 아래 주소를 입력하여 접속합니다.
   > http://localhost:3000/index.html
3. 브라우저 상단에 뜨는 '카메라 권한'을 반드시 [허용]해 줍니다.
4. 화면 좌측의 [▶ 자동 검수 시작] 버튼을 누릅니다.
5. 카메라 앞에 검수할 제품(자동차 모형)을 비추면, AI가 실시간으로 객체를 추적하여
   중복 없이 캡처하고 불량 여부를 스스로 판정합니다.

※ 주의사항
- 카메라가 켜지지 않으면 PC의 다른 프로그램(줌, 카카오톡 등)에서 카메라를 사용 중인지 확인하세요.
- Agent Log에 아무 반응이 없다면 1단계(백엔드 서버)가 켜져 있는지 확인하세요.
